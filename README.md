# raadioo

raadioo is a simple web player for online community radios inspired in an fm/am radio, where you can actually tune several stations.

more and more radios will be added gradually. you can fork and PR to add your favourite.

it is inpired in permacomputing principles, using native html elements where possible.

font: [Sligoil](https://velvetyne.fr/fonts/sligoil/)

more on permacomputing: [here](https://permacomputing.net/)

thanks [radio-browser](https://www.radio-browser.info/) for the streaming links.
