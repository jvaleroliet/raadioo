# raadioo

## Intro
*raadioo* is a simple web player for online community radios inspired in an fm/am radio, where you can actually tune several stations.

More and more radios will be added gradually. You can fork and PR to add your favourite.

It is inspired in permacomputing principles, using native html elements where possible.

- Logo font: [Redaction](https://www.redaction.us/)

- More on permacomputing: [here](https://permacomputing.net/)

- Thanks [radio-browser](https://www.radio-browser.info/) for the streaming links.

## Create your own *raadioo*!

If you want to create your own *raadioo*, just fork the repository, and modify the list of your favourite raadioos.

For each raadioo, the code snippet is:

```html
<option value="http://radio.stream">RADIO NAME</option>
```

You can search the stream link in [radio-browser.info](https://www.radio-browser.info/)

You can group radios within an optgroup element:

```html
<optgroup label="Some Label">
    ...
</optgroup>
```

Once is ready, you can use it locally (open the `index.html` file in your browser) and use it as a desktop app. 

If you want to use in multiple devices, you can deploy it with [Github Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site). You can choose a custom subdomain name, for example `yournickname.raadioo.org`. Just let me know opening an issue and I will add it.

You can personalize the page but remember to keep it simple and lightweight if you want me to add it :)
